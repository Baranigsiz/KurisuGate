# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of **KurisuGate** seriously. If you believe you have found a security vulnerability in the PII redaction engine, gateway authentication, or token caching layer, please do **NOT** open a public issue.

Instead, please send an email with the details, reproduction steps, and potential impact to:
**baranigsiz@users.noreply.github.com**

We will acknowledge your report within 48 hours and work diligently to release a patch promptly.
