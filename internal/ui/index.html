💻 Instant Drop-In Integration

KurisuGate is 100% OpenAI API compatible. Change two lines of code in any client or library:

Python (OpenAI Official SDK)

from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8080/v1",
    api_key="kg-dev-team"  # Your KurisuGate Virtual Key
)

response = client.chat.completions.create(
    model="smart",  # Aliases: smart, fast, claude, gemini, cheapest
    messages=[{"role": "user", "content": "Hello Kurisu!"}],
    stream=True
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="")

Node.js / TypeScript

import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "http://localhost:8080/v1",
  apiKey: "kg-dev-team"
});

const response = await client.chat.completions.create({
  model: "smart",
  messages: [{ role: "user", content: "Hello Kurisu!" }]
});

console.log(response.choices[0].message.content);

cURL

curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer kg-dev-team" \
  -d '{
    "model": "smart",
    "messages": [{"role": "user", "content": "Hello Kurisu!"}]
  }'
